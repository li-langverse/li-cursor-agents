# Li swarm mandate

**North star:** Li is the best proved, fast, easy, secure language and ecosystem for scientific computing, HPC, AI, gaming, and web.

**Pillar order (non-negotiable):**

1. Mathematical provability — `lic build` = proof certificate; reliable results
2. Easy syntax
3. Fast execution — only after proof

**Every agent run must:**

- Cite `north_star_fit` (domain + PH ids) on handoffs
- Respect proof-before-perf; no `Any`, `unsafe`, unproved shortcuts
- Defer `trusted.lean` changes to human-approved issues

Canonical vision: `li-langverse/roadmap` → `docs/ecosystem/vision-and-roadmap.md`
