# Swarm data directory

Runtime state for `li-cursor-agents`. **Do not commit** most files here (gitignored). A backup manifest may live outside the repo (e.g. `~/Documents/Cursor/backups/swarm-YYYYMMDD`).

## Live vs safe to delete

| Path | Live when | Safe to delete |
|------|-----------|----------------|
| `control-plane/` | Always while swarm runs | Stale `sdk-slots/*.lock` (dead PID) via `./scripts/sweep-hung-agents.sh --apply`. **Keep** `state.json` if systemd is active. |
| `control-plane/worker-status.json` | Legacy (unused) | Swarm state lives in Supabase `worker_status`; safe to delete stale file. |
| `latest/` | Dashboard briefing | Regenerated by enrich/supervisor; safe to delete for a clean briefing rebuild. |
| `lanes/state.json` | Lane runners | Small; recreated on next lane tick. |
| `handoffs/pending.jsonl` | Implement/maintenance lanes | Drained by lane processors; old lines can be trimmed manually. |
| `runs/*.json`, `runs/*.md` | Run history cache | Old files beyond retention (see `clean-swarm-data.sh`). **Never** delete active run IDs referenced in `control-plane/state.json`. |
| `runs/mock/` | CI / `CURSOR_MOCK=1` only | **Always safe** — excluded from dashboard and DB catalog. |
| `workspaces/` | Active `code_implementer` clones | Prune with `npm run workspace:prune` (default: keep 5 newest, max 20 per repo, drop older than 7 days). Dirty clones need `--force` or `LI_WORKSPACE_PRUNE_FORCE=1`. |
| `workspaces-test/` | Unit/e2e tests | Safe to remove anytime (not used in production). |
| `research-sessions/` | Research lane | Session JSON; delete only if you accept losing in-flight session context. |
| `archive/` | — | Tarballs from `scripts/clean-swarm-data.sh --apply`; safe to move off-disk after verify. |

## Not under `data/`

- **Config**: `config/` (YAML goals, queues) — source of truth, versioned in git.
- **Secrets**: `.env`, credentials — never delete or archive.
- **Build**: `dist/` — rebuild with `npm run build`.
- **Logs**: `logs/*.log` — rotate with `clean-swarm-data.sh` or truncate manually; keep recent for systemd debugging.

## Cleanup commands

```bash
# Report + optional archive (default dry-run)
./scripts/clean-swarm-data.sh
./scripts/clean-swarm-data.sh --apply

# Workspace clones only
npm run workspace:prune -- --dry-run
npm run workspace:prune -- --force

# Hung SDK locks / orphan agent PIDs (does not stop systemd units)
./scripts/sweep-hung-agents.sh
./scripts/sweep-hung-agents.sh --apply
```

## Layout

```
data/
├── control-plane/     # Supervisor + worker snapshots, SDK slot locks
├── latest/            # agent-briefing.json, remediation_manifest.json
├── lanes/             # Per-lane state (implement, research, …)
├── handoffs/          # pending.jsonl queue
├── runs/              # Per-run .json/.md (production)
│   └── mock/          # Ephemeral mock/CI artifacts
├── workspaces/        # Isolated git clones: {org}/{repo}/{agent}-{ts}/repo
├── workspaces-test/   # Test harness clones (disposable)
├── research-sessions/ # Research lane session store
└── archive/           # Optional tarballs from clean-swarm-data.sh --apply
```

## Confusing leftovers

- **Duplicate-looking control-plane files**: `latest-report.json` (supervisor) vs `latest/agent-briefing.json` (enriched briefing) serve different APIs — both are live.
- **Many `runs/*.json`**: Disk cache when Supabase is enabled; prune by age/count, not wholesale `rm`.
- **Plan-loop dirs** (`data/*-plan-loop/`): Retired; product loops moved to async swarm. Archive/remove if they reappear.
- **Huge `workspaces/`**: Normal under load; use workspace prune, not manual `rm -rf` on newest clones.
